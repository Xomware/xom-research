Oikos Black figure, red figure

The street painted on a pot. Houses are glaze figures with incised outlines on terracotta, each household gets a Greek letter medallion (Α, Β, Γ), and status is scratched on an ostracon, the potsherd Athenians wrote notes on. Light mode is black-figure, glaze on clay. Dark mode flips to red-figure, clay on glaze. Meander bands frame the chrome only; everything you read is set in Commissioner, with Marcellus kept for names.
